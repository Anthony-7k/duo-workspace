# 拾物 · DUO Workspace

数码设备与美妆用品合一的个人物品管理工作台。采用暖灰配色和液态玻璃界面，支持桌面与手机浏览。

## 当前功能

- 数码、美妆分类查看与关键词搜索。
- 新增、编辑、删除物品，撤销误删。
- 记录品牌、型号、价格、使用状态、收纳位置与备注。
- 保修、有效期及维修状态提醒。
- 浏览器本地自动保存与恢复。
- 液态玻璃边缘折射和随指针变化的高光。

## 本地打开

直接用浏览器打开根目录 `index.html`，或在本目录启动静态服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。推荐固定使用同一个访问地址，以便恢复浏览器保存的资料。

## 文件说明

```text
index.html              可直接部署的完整网页
src/workbench.html      页面与交互源码片段
styles/warm-theme.css   暖灰配色样式，已合并到页面源码
README.md               项目说明
```

目前页面源码和可部署网页是两个独立文件；修改源码后需要同步生成可部署页面，不能只修改源码片段。部分图标及预览运行时仍使用外部资源，国内网络访问需在目标托管环境实际验证。

## 数据说明

当前版本为前端应用。资料保存在每个浏览器自己的 localStorage 中，未接入云端数据库或跨设备同步。清除网站数据、换浏览器或更换访问域名，都可能无法读取原来的本地资料。

首次打开包含 6 条演示物品，当前交互预览最多录入 24 件物品。设备管理仅指资料管理，不连接、控制真实硬件。

当前提醒日期以演示版本的参考日期计算，后续可改为按当天日期自动更新。

## 部署

把根目录 `index.html` 上传到支持静态网页的托管服务即可，不需要额外的前端构建步骤。

GitHub 用于保存项目代码；上传仓库本身不代表已开通网站托管，也不会自动上传浏览器中的个人物品资料。
